Feature: AI-Estimator — генерация сметы из текстового описания

  # === Happy Path ===

  Scenario: Успешная генерация сметы из текстового описания
    Given пользователь авторизован как "manager" в тенанте "ООО РемСтрой"
    And выбран регион "77" (Москва)
    When вводит описание работ "Ремонт 2-комнатной квартиры 60м², демонтаж, электрика, штукатурка, покраска"
    And указывает площадь 60 м²
    And нажимает "Создать смету"
    Then получает смету с позициями по ГЭСН/ФЕР
    And каждая позиция содержит: код расценки, наименование, единица измерения, объём, цена за единицу, итого
    And применены актуальные квартальные индексы Минстроя для региона "77"
    And итоговая сумма > 0
    And время генерации < 60 секунд

  Scenario: Экспорт сметы в PDF и Excel
    Given смета "Ремонт квартиры Ленина 15" сгенерирована
    When пользователь нажимает "Экспорт" и выбирает формат "PDF"
    Then скачивается PDF-файл с шапкой (реквизиты компании), таблицей расценок и итогами с НДС
    When пользователь нажимает "Экспорт" и выбирает формат "Excel"
    Then скачивается .xlsx файл с аналогичным содержимым

  # === Error Handling ===

  Scenario: Слишком короткое описание работ
    Given пользователь авторизован как "manager"
    When вводит описание работ "ремонт" (6 символов)
    And нажимает "Создать смету"
    Then отображается ошибка "Описание должно содержать минимум 20 символов"
    And смета не генерируется

  Scenario: AI-провайдер недоступен
    Given пользователь авторизован как "manager"
    And Cloud.ru Foundation Models недоступен
    And OpenAI (fallback) недоступен
    When отправляет запрос на генерацию сметы
    Then отображается сообщение "AI временно недоступен"
    And предлагается "Создать смету вручную"

  Scenario: Лимит AI-смет по тарифу исчерпан

    When отправляет запрос на генерацию сметы
    Then получает ошибку "Лимит AI-смет по тарифу исчерпан"
    And отображается ссылка на страницу повышения тарифа
    And HTTP status = 429

  # === Edge Cases ===

  Scenario: AI выделяет позиции выше среднерыночной цены
    Given смета сгенерирована для объекта 100 м²
    And позиция "Укладка ламината" имеет цену на 15% выше среднерыночной
    Then эта позиция выделена жёлтым цветом
    And отображается подсказка с альтернативной расценкой

  Scenario: Генерация сметы для максимальной площади (200 м²)

    When вводит описание работ для объекта площадью 200 м²
