## Суть гибрида

> **СтройУправ** — mobile-first ERP для строительства и ремонта с **AI-сметчиком по ГЭСН/ФЕР** и **real-time dashboard всех объектов**. Одна платформа заменяет Excel + WhatsApp + 1С + бумажные сметы.

## Экраны финального CJM

### 1. Landing (Awareness → Acquisition)
- **Headline:** «Сметы за 5 минут. Объекты под контролем. AI-прораб 24/7.»
- **Sub:** Российское ERP для строительства: ГЭСН/ФЕР, КС-2/КС-3, бригады, бюджет — одно приложение
- **CTA primary:** «Попробовать бесплатно — 14 дней»
- **CTA secondary:** «Загрузить чертёж → Получить смету»
- **Social proof:** «4 700+ компаний перешли с Excel · Российское ПО · ГЭСН/ФЕР»
- **Микротренды:** 📱 Mobile-first, 📊 Прозрачность, 🤖 AI-сметы, 🏗️ Импортозамещение

### 2. Onboarding (Activation)
- **Path A (быстрый):** 4 вопроса → персонализация → создать первый объект
- **Path B (wow-эффект):** Загрузить чертёж/фото → AI распознаёт → мгновенная смета
- **Результат:** Персонализированный интерфейс + первый объект + первая смета за <5 мин
- **Микротренды:** 🤖 Computer Vision, ⚡ Zero-input, 📄 PDF/DWG parsing

### 3. Aha Moment (Activation → Retention)
- **Момент 1 (из A):** Dashboard всех объектов — прогресс, бюджет, бригады одним взглядом
- **Момент 2 (из C):** AI-смета по ГЭСН/ФЕР за 5 минут + AI-подсказка об оптимизации
- **Эмоция:** «Наконец-то я вижу ВСЁ + AI считает за меня!»
- **AI-подсказка:** «По объекту X вижу задержку 3 дня на электрике. Электромонтаж на 12% дороже рынка — проверьте позиции 47-52.»
- **Микротренды:** 🤖 AI-агент прораба, 🏗️ Digital twin, 📊 Бенчмарки по рынку

### 4. Core Loop (Retention — ежедневный)
- **Утро:** Push-дайджест → открыть приложение → утренний обход с фотофиксацией
- **День:** Задачи бригадам → контроль материалов → AI-алерты при отклонениях
- **Вечер:** P&L за день → факт vs смета → AI-прогноз завершения
- **Еженедельно:** Отчёт заказчику → автоматический КС-2 → индексы Минстроя
- **Hook:** AI-алерты + утренний дайджест + фотофиксация → привычка
- **Микротренды:** 📋 Auto-КС-2/КС-3, 🤖 AI-прогноз задержек, 📸 Фотофиксация, 📊 Факт vs план

### 5. Paywall (Revenue — день 14)
- **Framing:** ROI-based — «AI сэкономил вам ₽X за 14 дней trial»
- **Тарифы:**

| План | Цена/мес | Включено |
|------|----------|----------|
| **Бригадир** | ₽2 990 | 5 объектов, 2 юзера, базовые сметы |
| **Компания** | ₽9 900 | 30 объектов, 10 юзеров, AI-сметы, Gantt, КС-2 |
| **Генподрядчик** | ₽29 900 | ∞ объектов, ∞ юзеров, BIM, API, 1С-интеграция |
| **Enterprise** | ₽49 900 | On-premise, SLA, выделенный менеджер |

- **Якорь:** Enterprise ₽49 900 → Компания ₽9 900 кажется разумной
- **Freemium:** 1 объект + 3 сметы/мес навсегда бесплатно
- **Микротренды:** 💡 ROI-pricing, 🆓 Freemium hook

### 6. Referral (Viral)
- **Supply-side (из A):** Пригласи субподрядчика → он получает бесплатный «Бригадир» на 3 мес, ты → -10% подписки
- **Product-led (из C):** Каждая отправленная смета/отчёт → брендированная «визитка» → заказчик переходит на портал
- **Заказчик-портал:** View-only портал с прогрессом ремонта → заказчик привыкает → требует от следующего подрядчика
- **K-factor:** ~0.6-0.9 (3-7 субподрядчиков на компанию + product-led)
- **Микротренды:** 🔄 Экосистема, 📊 Портал заказчика
