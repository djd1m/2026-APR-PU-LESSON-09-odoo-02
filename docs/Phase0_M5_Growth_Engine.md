### Метрики Loop

| Этап | Метрика | Target | Источник/обоснование |
|------|---------|:------:|---------------------|
| Подрядчик → AI-смета | Сметы/мес на пользователя | >5 | Средний подрядчик ведёт 3-10 объектов |
| Смета → Заказчик | % смет отправленных через систему | >60% | Branded PDF/link — zero effort |
| Заказчик → Портал | % заказчиков, открывших портал | >40% | Push при обновлении прогресса |
| Портал → Требование | % заказчиков, потребовавших портал от нового подрядчика | >10% | [H] — ключевая гипотеза |
| Новый подрядчик → Регистрация | % конверсии по реф-ссылке | >25% | «Заказчик требует» = сильный мотиватор |
| **K-factor** | | **0.6-0.9** | 3-7 субподрядчиков × 10-25% конверсия |

## D. MOATS (ЗАЩИТНЫЕ РВЫ)

| Ров | Тип | Глубина | Время на копирование |
|-----|-----|:-------:|:--------------------:|
| **AI-модель на ГЭСН/ФЕР** | Data moat | 🔴 Глубокий | 18-24 мес (нужна обучающая выборка) |
| **Network effect (маркетплейс)** | Network | 🔴 Глубокий | 12-18 мес (chicken-and-egg) |
| **Sticky data** (объекты, сметы, бригады, история) | Switching cost | 🟡 Средний | Мгновенно (но данные не переносятся) |
| **Бренд / Trust** (рейтинги подрядчиков) | Brand | 🟡 Средний | 24-36 мес |
| **Интеграции** (1С, BIM, дроны) | Ecosystem | 🟡 Средний | 6-12 мес на каждую |

### 2nd-Order Effects

```
Больше подрядчиков → больше AI-смет → лучше AI-модель → точнее сметы
→ больше подрядчиков (data flywheel)

Больше объектов → больше данных о реальных расходах
→ лучше бенчмарки по рынку → ценнее AI-подсказки
→ выше retention → больше объектов (insights flywheel)
```
