## D. КОНКУРЕНТНАЯ ДИНАМИКА (Game Theory)

### Игра: «Вход СтройУправ на рынок»

**Игроки:** 1С:УСО (доминант), Аспро.Cloud (challenger), СтройУправ (entrant)

| Стратегия СтройУправ | Реакция 1С:УСО | Реакция Аспро.Cloud | Итог для СтройУправ |
|----------------------|---------------|---------------------|---------------------|
| **Фронтальная атака** (конкурировать по ERP-глубине) | Снижение цены, кросс-продажа с 1С:Бух | Игнорирование | ❌ Проигрыш — нет шансов против 1С-экосистемы |
| **Нишевая специализация** (ремонт + малый бизнес) | Игнорирование (слишком мелкий сегмент) | Может скопировать | ⚠️ Риск — Аспро уже там |
| **Disruptive** (AI-сметы + mobile + freemium) ⭐ | Не может быстро ответить (legacy архитектура) | Может попробовать AI, но нет R&D | ✅ **Оптимальная стратегия** |

### Nash Equilibrium

**СтройУправ:** Disruptive entry через AI-сметы (уникальная capability, которую legacy-игроки не могут быстро скопировать) + freemium (снижает барьер) + mobile-first (другая парадигма).

**1С:УСО:** Будет игнорировать первые 12-18 мес (стандартная реакция incumbents на disruptors), затем попытается добавить мобильное приложение, но legacy-архитектура ограничивает.
