# Product Requirements Document: СтройУправ

## Product Brief

**Product Name:** СтройУправ
**Tagline:** Mobile-first ERP для строительства и ремонта с AI-сметчиком
**Problem Statement:** Строительные и ремонтные компании РФ управляют проектами через Excel + WhatsApp + 1С + бумажные сметы. Это приводит к непрозрачности бюджетов, срывам сроков (40% заказчиков), потере данных при уходе сотрудников и невозможности масштабирования.
**Target Users:** Ремонтные компании (5-50 чел.), генподрядчики (50-500 чел.), частные мастера
**Core Value Proposition:** Смета за 5 минут по ГЭСН/ФЕР + все объекты в одном экране + AI-прогнозы — заменяет 5-7 инструментов одним приложением

---

## 1. Vision & Strategy

### Vision Statement
Стать стандартом управления строительными проектами в РФ — как Procore для США, но с российской сметной базой, AI-сметчиком и mobile-first подходом.

### Strategic Context
- Рынок ПО для строительства РФ: ₽6.4 млрд (2024) → ₽25 млрд (2028), CAGR ~40%
- BIM/ТИМ обязателен с 2024 — принудительная цифровизация
- Импортозамещение: 70% рынка — российское ПО, ниша «российский Odoo для стройки» пуста
- Odoo ($650M ARR, 13M users) не имеет строительных модулей из коробки

### Business Model
- **Primary:** SaaS-подписки (₽2 990 — ₽49 900/мес), 4 плана
- **Secondary:** AI-сметы usage-based (₽490/смета сверх лимита), marketplace-комиссия 3-5%
- **Freemium:** 1 объект + 3 AI-сметы/мес бесплатно

## 2. Target Users & Personas

### Persona 1: Руководитель ремонтной компании (Алексей)
- **Кто:** 35-45 лет, управляет компанией 10-30 чел., 5-15 объектов одновременно
- **Боль:** «Каждый вечер сижу в Excel, свожу данные по объектам. Прораб уволился — и вся информация пропала»
- **Job:** «Помоги мне управлять 10 объектами, 5 бригадами и 20 поставщиками без хаоса»
- **Current solution:** Excel + WhatsApp + 1С:Бухгалтерия (~₽10K/мес)
- **Trigger:** Убыточный объект из-за непрозрачного учёта

### Persona 2: Прораб / Бригадир (Сергей)
- **Кто:** 30-50 лет, управляет 1-3 объектами, 5-15 рабочих
- **Боль:** «Весь день на объекте, отчёты — по ночам. Заказчик звонит каждый час спрашивать про прогресс»
- **Job:** «Дай мне инструмент в телефоне, чтобы фиксировать прогресс и отчитываться одной кнопкой»
- **Current solution:** Блокнот + Telegram + звонки
- **Trigger:** Заказчик отказался платить из-за отсутствия фотофиксации

### Persona 3: Заказчик ремонта (Ольга)
- **Кто:** 30-55 лет, владелица квартиры, заказывает ремонт впервые или повторно
- **Боль:** «Подрядчик обещал 2 месяца — делает 5. Куда ушли деньги — непонятно»
- **Job:** «Хочу видеть прогресс ремонта в реальном времени и не бояться обмана»
- **Current solution:** WhatsApp-чат с прорабом + сарафанное радио
- **Trigger:** Обожглась на предыдущем ремонте

## 4. User Stories (MVP)

### Epic: AI-сметчик (F01)

```
US-01: Как руководитель ремонтной компании,
       я хочу получить смету по ГЭСН/ФЕР за 5 минут,
       чтобы быстро оценить стоимость нового объекта.

       AC:
       - Ввожу текстовое описание работ → получаю смету в формате таблицы
       - Смета содержит расценки по ГЭСН/ФЕР с актуальными индексами
       - Могу экспортировать в PDF и Excel
       - AI подсказывает позиции, где цена выше среднерыночной (>10%)

US-02: Как прораб,
       я хочу загрузить чертёж и получить предварительную смету,
       чтобы не считать вручную объёмы работ.

       AC:
       - Загружаю PDF/фото чертежа → AI распознаёт помещения и площади
       - AI определяет виды работ и подбирает расценки
       - Точность распознавания площадей ≥ 85%
       - Могу скорректировать результат вручную
```

### Epic: Dashboard объектов (F02)

```
US-03: Как руководитель,
       я хочу видеть все мои объекты на одном экране,
       чтобы понимать общую картину бизнеса.

       AC:
       - Dashboard показывает: объект, прогресс %, бюджет факт/план, сроки
       - Объекты с отклонениями выделены цветом (зелёный/жёлтый/красный)
       - Могу отфильтровать по статусу, типу работ, бригаде
       - Dashboard загружается < 2 секунд
```

### Epic: Управление задачами (F03)

```
US-04: Как прораб,
       я хочу создать задачу и назначить на бригаду с телефона,
       чтобы не звонить каждому отдельно.

       AC:
       - Создание задачи: название, описание, бригада, срок, приоритет
       - Push-уведомление бригаде при назначении
       - Статусы: новая → в работе → на проверке → выполнена
       - Подзадачи и зависимости
```

### Epic: Фотофиксация (F04)

```
US-05: Как прораб,
       я хочу сфотографировать выполненную работу и привязать к задаче,
       чтобы заказчик видел прогресс без звонков.

       AC:
       - Фото с автоматическим геотегом и timestamp
       - Привязка к задаче/этапу
       - Авто-обновление прогресса объекта
       - Фото доступны в портале заказчика (P1)
```

## 7. Constraints & Assumptions

### Constraints
- **Architecture:** Distributed Monolith в Monorepo (Docker + Docker Compose на VPS)
- **AI Provider:** Cloud.ru Foundation Models (primary) + OpenAI/Anthropic (fallback) через LiteLLM
- **Database:** PostgreSQL (Odoo-совместимый)
- **Deploy:** Docker Compose на VPS (AdminVPS/HOSTKEY)
- **Budget:** Pre-seed ₽5-10М (8 чел. команда, 3 мес до MVP)
- **Compliance:** 152-ФЗ (персональные данные), сметные нормативы РФ

### Assumptions
- AI-модели Cloud.ru/Qwen3 достаточны для парсинга и расчёта смет по ГЭСН/ФЕР
- Ремонтные компании готовы платить ₽3-10K/мес за SaaS (валидация через MVP)
- Odoo Community (LGPL-v3) может быть форкнут как основа backend без юридических рисков
- Freemium-модель обеспечит достаточный inbound (AI-смета = lead magnet)

## 8. Risks

| Risk | Probability | Impact | Mitigation |
|------|:-----------:|:------:|------------|
| AI-сметы < 80% точности | Medium | High | Hybrid: AI-черновик + ручная доработка |
| CAC > ₽50K | Medium | High | PLG (бесплатные AI-сметы) как zero-CAC канал |
| Конкуренция с 1С:УСО | Low | Medium | Не заменять 1С:Бухгалтерию — интегрироваться |
| Churn > 8% | Medium | High | Sticky data + портал заказчика |
| Команда: нет domain-эксперта по стройке | High | Medium | Нанять прораба/сметчика как advisor |
