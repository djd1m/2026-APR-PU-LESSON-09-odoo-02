# Руководство пользователя

## Создание объекта

1. Войдите в систему и перейдите на Dashboard объектов.
2. Нажмите **"Новый объект"**.
3. Заполните поля: название, адрес, тип работ (ремонт / строительство), заказчик.
4. Укажите плановый бюджет и сроки (дата начала и дата окончания).
5. Назначьте ответственного прораба.
6. Нажмите **"Создать"**. Объект появится на Dashboard.

На Dashboard объекты отображаются с индикаторами:
- Зелёный -- всё по плану
- Жёлтый -- есть отклонения (бюджет или сроки)
- Красный -- критические отклонения

## Генерация AI-сметы

1. Откройте объект и перейдите в раздел **"Сметы"**.
2. Нажмите **"Новая AI-смета"**.
3. Введите текстовое описание работ или загрузите чертёж (PDF/фото).
4. Система сгенерирует смету по ГЭСН/ФЕР с актуальными индексами Минстроя.
5. Просмотрите результат. AI подсветит позиции, где цена выше среднерыночной на 10%+.
6. Скорректируйте позиции вручную при необходимости.
7. Нажмите **"Утвердить"** для фиксации сметы.
8. Экспортируйте в PDF или Excel через кнопку **"Экспорт"**.

Время генерации: до 60 секунд для объекта до 200 м2.

Лимиты: бесплатный план -- 3 AI-сметы/мес, платные планы -- по тарифу. Сверх лимита -- 490 руб/смета.

## Управление задачами

1. Откройте объект и перейдите в раздел **"Задачи"**.
2. Нажмите **"Новая задача"**.
3. Заполните: название, описание, назначьте бригаду, укажите срок и приоритет.
4. При необходимости добавьте подзадачи и зависимости.
5. Назначенная бригада получит push-уведомление.

Статусы задач:
```
Новая -> В работе -> На проверке -> Выполнена
```
Любую задачу (кроме выполненной) можно отменить. Отменённую задачу можно реактивировать.

Переводить задачу в статус "Выполнена" или "Отменена" может только менеджер или администратор.

## Фотофиксация

1. Откройте задачу с мобильного устройства (PWA).
2. Нажмите **"Добавить фото"**.
3. Сделайте снимок -- геотег и время проставляются автоматически.
4. Фото привязывается к задаче и этапу работ.
5. Прогресс объекта обновляется автоматически.

Ограничения: максимальный размер файла -- 20 МБ. Поддерживаются форматы JPEG и PNG.

## Бюджет в реальном времени

1. На Dashboard объекта перейдите в раздел **"Бюджет"**.
2. Система показывает соотношение "факт / план" по каждой статье.
3. AI-алерты срабатывают при отклонении факт/план более 10%.
4. Прогресс рассчитывается по взвешенной трудоёмкости задач.
5. Health score объекта (зелёный/жёлтый/красный) учитывает: отклонение бюджета, просроченные задачи, отставание прогресса.

## Подписки и оплата

1. При регистрации доступен бесплатный план: 1 объект + 3 AI-сметы/мес.
2. Для перехода на платный план откройте **"Настройки" -> "Подписка"**.
3. Выберите план (от 2 990 до 49 900 руб/мес).
4. Оплата через ЮKassa: банковские карты, СБП, ЮMoney.
5. Пробный период: 14 дней на любом платном плане.
6. Рекуррентные платежи -- автоматическое списание каждый месяц.
