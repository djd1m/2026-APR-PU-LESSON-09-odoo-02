# Project Context: СтройУправ

## Domain Terminology

| Термин | Расшифровка | Использование в проекте |
|--------|-------------|------------------------|
| **ГЭСН** | Государственные элементные сметные нормы | База расценок для AI-сметчика (федеральный уровень) |
| **ФЕР** | Федеральные единичные расценки | Расценки с учётом накладных (федеральный уровень) |
| **ТЕР** | Территориальные единичные расценки | Региональные расценки (привязка к субъекту РФ) |
| **КС-2** | Акт о приёмке выполненных работ | Первичный документ между подрядчиком и заказчиком |
| **КС-3** | Справка о стоимости выполненных работ | Сводный финансовый документ по КС-2 |
| **BIM/ТИМ** | Building Information Modeling / Технологии информационного моделирования | Обязателен с 2024 для жилья с госфинансированием |
| **Индексы Минстроя** | Квартальные коэффициенты пересчёта | Применяются к базовым расценкам ГЭСН/ФЕР |
| **Генподрядчик** | Главный подрядчик проекта | Целевой сегмент (50-500 чел.) |
| **Субподрядчик** | Подрядчик, нанятый генподрядчиком | Viral loop: приглашение через систему |
| **Прораб** | Производитель работ | Ключевой пользователь mobile-приложения |
| **Смета** | Документ с расчётом стоимости работ | Core feature: AI-генерация по ГЭСН/ФЕР |

## Odoo Module Patterns

### Naming Convention
- Module directory: `su_<domain>` (su = СтройУправ)
- Model name: `su.<domain>` (Odoo dot notation)
- Table name: `su_<domain>` (auto-generated by Odoo)

### Module Map
| Module | Odoo Name | Description |
|--------|-----------|-------------|
| `su_estimate` | `su.estimate` | AI-сметы, позиции ГЭСН/ФЕР, экспорт |
| `su_project` | `su.project` | Объекты строительства, dashboard |
| `su_task` | `su.task` | Задачи, бригады, зависимости |
| `su_photo` | `su.photo` | Фотофиксация с геотегом |
| `su_budget` | `su.budget` | Бюджет факт/план, AI-алерты |
| `su_billing` | `su.subscription` | Подписки, ЮKassa, trial |
| `su_portal` | `su.portal` | Портал заказчика (view-only) |
| `su_onboard` | `su.onboard` | Onboarding quiz, персонализация |

## Russian Market Context

- **152-ФЗ**: персональные данные граждан РФ должны храниться на территории РФ
- **Импортозамещение**: предпочтение российскому ПО в госзакупках
- **ЮKassa**: основной платёжный провайдер для RU SaaS (рекуррентные платежи)
- **Cloud.ru**: российский облачный AI-провайдер с OpenAI-compatible API

## When to Use This Skill

- При генерации кода модулей `su_*` — для правильной терминологии
- При работе со сметами — для понимания структуры ГЭСН/ФЕР
- При генерации документов КС-2/КС-3 — для соответствия ГОСТ
- При обсуждении архитектуры — для понимания regulatory constraints
